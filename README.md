# JoshOps AI

**Your PothOS. Your ArcheAgent. Your devices and ongoing work.**

JoshOps AI is one application and operating stack across its supported desktop, touch, web, CLI, TUI and MCP surfaces. PothOS provides each person's continuity and workspace inside that application; their ArcheAgent carries their own identity, responsibilities and permitted work.

Founded and designed by **Joshua David Gustafson-Juarez**. The project welcomes community development for local AI sovereignty, accessibility and useful work in personal, nonprofit, business and developer environments.

## Release staging

This repository is **private while release staging is reviewed**. Joshua will decide when to make it public. Its historical repository name is retained; the application people download is JoshOps AI.

Existing installations are verified on Mac Intel, Mac Apple Silicon, Linux x86_64, iPhone and iPad. Windows x86_64 and Android ARM64 version 1.0.8 packages have now been built from the reconciled master source and independently hash-verified. They are unsigned private candidates for review; recipient acceptance and public distribution are still separate. Installed-app evidence, package availability and store approval are recorded separately in the [release manifest](docs/release-artifacts.json).

The website is the doorway to the existing master application. Platform builds reuse the common application and preserve device-specific capabilities. A connected recipient package does not contain the founder's personal corpus, credentials or fleet bindings.

## Build with us

Use the [developer participation form](https://github.com/joshuagjuarez/PothOS-by-JoshOps-AI/issues/new?template=developer-participation.yml) to identify your platform, contribution area and whether you represent yourself or a team. An issue records a request; the maintainer assigns approved work and access separately.

Contribute UI improvements, reusable workflows, adapters, documentation, accessibility checks and reproducible fixes through issues and pull requests. Official updates are reviewed and verified before distribution. Each participant keeps their own accounts, private data and permissions.

## Price, rights and privacy

Official software is intended to remain free. Optional provider subscriptions, hardware and hosting have their own costs. Existing license grants remain effective; the final runtime source license and public package promotion are tracked in [license status](LICENSE_STATUS.md).
