# PothOS support and contributions

Use this repository as the public home for PothOS reports and contributions.

| Need | Route |
| --- | --- |
| Report a reproducible bug or documentation problem | [Open an issue](https://github.com/joshuagjuarez/PothOS-by-JoshOps-AI/issues/new/choose) |
| Propose a focused improvement | [Contribution guide](CONTRIBUTING.md) and [issue templates](https://github.com/joshuagjuarez/PothOS-by-JoshOps-AI/issues/new/choose) |
| Discuss where to contribute | [Start-here discussion](https://github.com/joshuagjuarez/PothOS-by-JoshOps-AI/issues/1) |
| Report a vulnerability or a private concern | [Security reporting](SECURITY.md) or [joshua@joshops.ai](mailto:joshua@joshops.ai) |
| Follow proposed changes | [Pull requests](https://github.com/joshuagjuarez/PothOS-by-JoshOps-AI/pulls) |
| Check what is actually released | [Release status](docs/RELEASE_STATUS.md) |

## What happens to a report

The maintainer reviews the report, asks for the smallest useful reproduction
when needed, and links accepted work to its issue or pull request. An issue is
not a promise that a feature will be built or a deadline will be met. Current
capacity does not support a guaranteed response time.

GitHub issue and pull-request conversations are the public record. Automatic
delivery into the maintainer's private support system is still being qualified;
opening an issue does not establish a second private case or grant system access.

Reports should identify the document or version, expected and observed
behavior, and a reduced example. The current repository contains documentation
and release preparation; standalone runtime source is not yet released.

## Share only the information needed

Issues, comments and pull requests are public. Use synthetic examples and remove
credentials, recordings, private memory and other people's information before
posting. Public contributions never authorize access to a contributor's device,
private environment or data. Private support messages are not automatically
authorized for public quotation.
