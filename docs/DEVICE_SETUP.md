# Build around your devices

**JoshOps AI is the application. PothOS and your ArcheAgent are inside it.** The interface is one way to participate; the environment also holds memory, files, supported models, tools and ongoing workflows.

## 1. Choose a local home

A Mac, Windows or Linux computer can be the continuing home for your environment. It keeps its normal operating system and can provide storage, supported local compute and tools. A lab or team can use an admitted shared computer rather than buying one computer per phone.

The Windows, Android and notarized Apple-silicon Mac previews use the existing account service. The complete standalone Python/runtime and local model packages are still being prepared. Intel Mac and Linux recipient installers remain separate release work. See [the exact download routes](DOWNLOADS.md).

## 2. Add your phone or tablet

The touch device is a participant, with its own device identity, local workspace and supported capabilities. Its simple orb presentation does not describe the entire runtime. A compatible phone can also run a supported local engine when its model is available; device and platform permissions still apply.

For current connected workflows, enroll the device with the same permitted environment and verify the return from that device. The Android package contains native engine libraries but does not bundle model weights. The signed iOS/iPadOS app exists on enrolled devices; a public App Store or TestFlight invitation is not yet published. A web-app installation is a separate connected access option.

A home computer is the practical setup path for continuing local work. It is not a claim that every phone task inherently requires a laptop, or that an iPhone runs an unrestricted background server. Phone-only independence is being developed and tested separately. [Phone capabilities and lifecycle](PHONE_NODES.md).

## 3. Connect an assistant

Use your own admitted account and the [connection guide](CONNECTIONS.md). A supported MCP client can call the tools exposed to that account. A successful connection proves that route; it does not install missing model weights or authorize every app on a device.

Start with one useful task: save a work note, recover the same note in a new session, then run an admitted workflow and inspect its result. Keep the same work and request identifiers if a response is interrupted.

## Choose what you have

Start at the [download page](https://joshops.ai/download) for an available installer or [use the web app](https://pothos.joshops.ai/install). No GitHub account or developer role is required to use the published files. Native iOS store delivery and Intel Mac/Linux recipient installers remain separate release work. If you want to contribute development or testing, the [optional contributor form](https://github.com/joshuagjuarez/PothOS-by-JoshOps-AI/issues/new?template=developer-participation.yml) collects your platforms and proposed work. You can participate without a phone, without a personal computer, or as part of a lab; select the corresponding option. Do not post passwords or private account information.
