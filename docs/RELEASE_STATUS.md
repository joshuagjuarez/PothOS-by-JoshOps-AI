## Connections and participation

- The public connection kit is **0.3.2**, with plugin source and setup configuration. It is not the standalone runtime or a model installer.
- The app and plugin operate through each participant's own account, allowed tools and enrolled devices. ChatGPT and Gemini CLI routes are documented; other client paths need their own acceptance evidence.
- Phones participate as separately addressed nodes. The default orb presentation, supported local engine and remote fleet route are distinct. Full interactive touch UI and unrestricted always-on phone serving are not claimed.
- The existing account service now separates free Personal registration, Developer profile enrollment and verified Enterprise membership. Shared HelpDesk/Huddle and the optional Halo view use the same app. New Enterprise checkout remains closed pending its actual membership instrument.
- Public issue forms, Discussions, contribution instructions and sponsorship proposals are available. A public download does not require access to private Founder repositories.

## Apple binary milestone

Apple processed the existing iOS/iPadOS build as VALID and APP_STORE_ELIGIBLE. That establishes binary processing, not App Review approval. The existing draft has the build attached. Review access, content-rights and encryption declarations, availability, screenshots, age rating and App Privacy remain part of submission preparation. The existing draft's free base-app price was verified; Enterprise membership is separate. Preserve the existing build when continuing this work.
