## Connections and participation

- The public connection kit is **0.3.2**, with plugin source and setup configuration. It is not the standalone runtime or a model installer.
- The app and plugin operate through each participant's own account, allowed tools and enrolled devices. ChatGPT and Gemini CLI routes are documented; other client paths need their own acceptance evidence.
- Phones participate as separately addressed nodes. The default orb presentation, supported local engine and remote fleet route are distinct. Full interactive touch UI and unrestricted always-on phone serving are not claimed.
- The shared backend now keeps diagnostics available when provider ownership proof fails. That recovery does not itself complete provider grants or plugin-to-phone delivery.
- Public issue forms, Discussions, contribution instructions and sponsorship proposals are available. A public download does not require access to private Founder repositories.
